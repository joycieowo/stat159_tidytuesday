# TidyTuesday: UK Baby Names

This project explores baby names across England & Wales, Northern Ireland, and Scotland.

Two complementary analyses examine how popular-name rankings compare across regions and over time, and how the diversity of boys' and girls' names differs by region in 2024.

- [Ranking comparisons and top-name overlap](results.md)
- [Name diversity by sex and region](name-diversity.md)
- [Data sources and definitions](data-sources.md)

The analysis code is in `uk_baby_name_rankings.py` and `script/unique_boys_girls_names.ipynb`.
